# MOBICAT

마비노기 모바일 PC버전 AI커넥트 기능 대응 Windows 보조 콘솔 프로그램입니다.
연주, 연주회, 생활 및 다양한 오버레이 기능 지원

> **고지:** MOBICAT 은 **유저가 만든 비공식 도구**입니다. **넥슨(Nexon) · 데브캣(devCAT)과 무관**하며, 그들이 만들거나 보증하지 않았습니다. MOBICAT 은 게임이 함께 설치하는 **공식 AI 커넥트 CLI 데이터만** 씁니다. 게임 파일을 고치지 않고 게임 프로세스에 들어가지 않으며, 오버레이는 게임 위에 띄우는 별도 창입니다.

## 기능

| 기능 | 한 줄 |
|---|---|
| 연주 | 가진 악보를 찾아 고르고, 지금 연주 상태를 봅니다 |
| 대기열 | 혼자 칠 곡을 줄 세워 차례로 칩니다 |
| 동시 시작 | 여럿이 약속 시각에 함께 연주를 시작합니다 |
| 연주회 준비 | 셋리 · 명부 · 자리 배치 · 세션 역할을 준비하고 연주회 날 진행을 돕습니다 |
| 생활 | 가공 시설 진행 · 생활 루틴을 보고 관리합니다 |
| 오버레이 | 게임 위에 연주 · 세션 · 생활 · 미션 카드를 띄웁니다(자리 · 모양 · 스킨 선택) |

<!-- 스크린샷 자리: 게임 위 오버레이 카드 (사용자가 넣음) -->

게임에 명령을 보내는 기능은 **기본이 꺼져 있고**, 사용자가 켠 것만 동작합니다. 결과를 모르면 다시 보내지 않습니다.

## 설치

1. [Releases](https://github.com/EarlGreyPie/MOBICAT_Releases/releases/latest) 에서 **`MOBICAT.App-stable-Setup.exe`** 를 받아 실행합니다. 관리자 권한은 없어도 됩니다.
2. 파란 **"Windows의 PC 보호"** 창이 뜨면 `추가 정보` → `실행`. 서명되지 않은 프로그램이라 처음 설치할 때 한 번 뜹니다.
3. 게임에서 **설정 → 게임 → `마비노기 모바일 AI 커넥터 Beta`** 를 켭니다. 7일 동안 쓰지 않으면 게임이 이 옵션을 저절로 끕니다.
4. MOBICAT 홈 탭 머리줄이 `게임 연결됨` 으로 바뀌면 준비 끝입니다.
5. 자동 업데이트는 설치판에서만 가능합니다. Portable(zip)이용자 분들은 판올림시 다시 새 zip 파일을 받아주세요. 사용자 데이터는 다른 위치에 저장되서 교체 가능합니다.

설치판은 사용자 폴더(`%LOCALAPPDATA%\MOBICAT.App`)에 깔리고 위치를 고를 수 없습니다. 원하는 폴더에 두고 싶으면 **`MOBICAT.App-stable-Portable.zip`** 을 받아 아무 폴더에나 풀어 `MOBICAT.exe` 를 실행하세요(설치 없이, 앱 안 업데이트도 됩니다).
0.9.2에서 설치위치 지정기능 대응 예정입니다.

업데이트는 앱이 알려 주고 받습니다.
(설정 → 일반 → `업데이트`, 모두 옵션). 

사용자 설정과 기록은 
`%LOCALAPPDATA%\MOBICAT` 에 있습니다.
업데이트 · 제거와 상관없이 남습니다.

**완전히 지우기:** 
제거(Windows 설정 → 앱 → `MOBICAT` 제거)는 앱 파일만 지우고 설정 · 셋리 · 즐겨찾기 같은 사용자 자료(`%LOCALAPPDATA%\MOBICAT`)는 남깁니다(다시 설치하면 이어짐). 

완전히 지우려면 제거한 뒤 해당 폴더를 지우세요. 
휴대용 zip 은 폴더째로 지우고 
사용자 자료 폴더를 지우시면 됩니다.
